# 雷同关系矩阵 · 静态原型

直接双击根目录的 `index.html`，即可在浏览器查看和操作，无需安装依赖、启动 Vite、配置 API Key 或连接网络。

## 交付文件

- `index.html`：页面入口。
- `prototype.css`：页面样式。
- `prototype.js`：原生交互和详情页跳转。
- `matrix-data.js`：首页与详情共用的单位、统计及示例明细。
- `pair-filter.js`：四个详情子页的双单位数据适配。

首页直接双击打开。详情依赖上一级的 `tab-page.html`、`unit-filter.js` 和 `围串标/`、`雷同性/`、`股权/`、`清单/` 目录，分享或部署时请保留整个目录结构。

## 保留功能

- 7 家投标单位的 7 × 7 雷同矩阵，包含单位自身维度。
- 21 组两两比对记录的表格视图。
- 全部、高危、中危、正常筛选：矩阵淡化不匹配项，表格只显示匹配项。
- 矩阵悬浮概况；点击色块、表格记录或“查看详细分析”在新窗口打开 `../tab-page.html`，传入 `unitA`、`unitB` 完整单位名称。详情仅展示所选组合；对角线展示单位自身维度。
- 窄屏横向滚动、键盘操作和 Esc 关闭悬浮提示。

示例数据沿用原项目：东棚与热地亚的比对以及这两家单位的自身维度触发 4 项规则、9 个问题（关键指标 1、文件雷同 2、股权关系 3、清单错误 3），其余记录正常。中危表格无记录属于预期结果。详情明细是与首页数量一致的原型示例，非实际检测证据。详情页顶部及各页签显示对应问题数量，正常组合显示无问题。原详情页面修改前已保存 `.matrix-backup` 备份。

## 原项目源码

`src/`、`public/`、`package.json`、`vite.config.ts` 等原始文件保留供追溯，静态原型不依赖这些文件。原 React 源码与静态原型为独立版本，修改源码不会自动更新静态页面。后续修改原型请编辑上述交付文件。

股权关系示例包含共同控股、主要人员交叉任职、年报邮箱相同；清单错误示例包含定额工程量错误、材料错别字、材料规格型号不规范。所有内容均为虚构原型数据，股权详情仍支持问题类型筛选。

## 单位自身分析

点击对角线“自身”方框打开本目录 `tab-page.html`，含两个页签：默认“清单审查”加载 `review-list.html`；“异常行为分析”加载 `../围串标/bid-exception-list.html`。单位名称通过 `unit` 参数传递，页签切换和新窗口打开均保留该参数。

清单审查列为：序号、单位名称、清单符合性检查、措施项目符合性检查、其它项目符合性检查、计算错误检查、取费检查、清标结果。当前 7 家单位的审查示例均无异常，检查项显示 `--`，清标结果显示“无异常”。

东棚与热地亚保留投标行为异常示例：页数超过阈值、未下载招标文件；其他单位投标行为无异常。自身方框按清单审查与投标行为两项状态计数并着色，悬浮展示各自是否异常。两两比对数据保持原有独立统计。新增 `self-behavior.js` 负责异常页数据筛选。
